# Curriculum and Resource Catalogue

## Why the catalogue exists

SETU must not have “one dataset.” It needs a catalogue describing resources across board, academic year, grade, subject, medium/language, edition, chapter, source, format and allowed use. The catalogue is metadata; the books themselves may remain on an official source host, in a user's private upload area, or in an open-licence collection.

A board appearing in a dropdown does not mean all subjects/classes are supported. The initial public coverage must be based on exact resources whose destination, language, version and permitted actions have been verified.

## Official sources to start with

### 1. Telangana SCERT

- Official domains: [scert.telangana.gov.in](https://www.scert.telangana.gov.in/) and [scert.telangana.gov.in](https://scert.telangana.gov.in/).
- Research found an official E-Books page indexed as **TEXT BOOKS (I TO X) – 2025–26**, with class/medium/subject codes. The indexed Class 8 table included Mathematics, Physical Science, Biological Science, Social Studies, English and media/language rows such as Telugu, English, Urdu and Hindi. Another indexed Classes 6–7 table included codes like `6EM_MAT`, `6TM_GS`, `6TM_SS`, `7EM_MAT`, `7EM_GS`, `7EM_SS` and language content.
- Discovery link (dynamic/encoded; not a stable API contract): [official indexed e-books page](https://www.scert.telangana.gov.in/Home.aspx/NarasimhaSatakam/BhaskaraSatakam/Pdf/PDF/publication/bed/pdf/DisplayContent.aspx?encry=ammkNW4%2Fgx+NeApstGPX+A%3D%3D).
- Another indexed listing: [official Class 6–7 textbook table](https://scert.telangana.gov.in/DisplayImage.aspx?encry=+J9U0B1hNdhJSYNXCM30vQ%3D%3D).
- **Download reality:** SCERT links may be rendered through dynamic/encoded destinations. Do not guess PDF URLs from resource codes. Verify each direct destination and academic year, then store the observed URL and verification timestamp. Use the official portal as fallback.

### 2. NCERT national textbooks

- [NCERT textbook selector](https://ncert.nic.in/textbook.php)
- [ePathshala textbook selector](https://epathshala.nic.in/wp-content/doc/book/btextbook/textbook.htm)
- The NCERT portal says the selector covers classes I–XII in Hindi, English and Urdu and offers chapter/full-book downloads through its official flow.
- **Critical rights rule:** NCERT's copyright notice says textbook republication, redistribution, rehosting and use in digital content packages/software are prohibited; it also says links may require written permission. Do not mirror NCERT PDFs or bundle them into SETU/offline lessons unless appropriate written rights allow it. Obtain permission/legal guidance before integrating the links into a public service if the notice applies.
- Direct test PDF found in official search: [Class X Science prelims PDF](https://www.ncert.nic.in/textbook/pdf/jesc1ps.pdf). This is an introductory/prelims PDF, not a full book. It is suitable only to test a link/open flow; it does not grant redistribution rights.
- Portal example for an older Class 8 Maths series: [NCERT maths selector example](https://ncert.nic.in/textbook.php?hemh1=0-16). Reconfirm the edition/curriculum before use; legacy chapters may not match newer books.

### 3. DIKSHA

- [DIKSHA portal](https://diksha.gov.in/)
- [Government overview](https://pmevidya.education.gov.in/diksha.html)
- [DIKSHA terms](https://diksha.gov.in/term-of-use.html)
- The Government overview highlights QR-linked textbook content, region/class selection, multiple Indian languages and offline use in the DIKSHA app. DIKSHA is a strong discovery/source reference.
- **Rights rule:** licensing and attribution apply, but conditions vary by item. Save each item's original URL, creator, licence, attribution and allowed actions. Do not assume the whole catalogue is universally reusable.
- **API rule:** this research did not establish a stable public unauthenticated content-search/download API contract suitable for immediate production. Do not invent endpoints. Start with verified links; investigate official API access only after checking current developer docs and terms.

### 6. Maharashtra — eBalbharati

### 7. Kerala SCERT

- [Official SCERT Kerala portal](https://scert.kerala.gov.in/).
- Search results in October 2026 show revised textbook notices for classes including 6, 8 and 10 and current 2026–27 curriculum-related notices. Follow the current book/resource links from the official portal; verify medium, academic year and direct file destination individually.

### 8. Openly licensed reference media

- [Openverse API](https://api.openverse.org/v1/) and [Openverse docs](https://docs.openverse.org/)
- [Creative Commons reuse guide](https://creativecommons.org/reusing-cc-licensed-content/)

## Resource discovery is not file hosting

Each entry needs separate actions:

- `open_source`: open the official/source page.
- `download_source`: follow the permitted official download flow, without proxying unless allowed.
- `import_to_private_workspace`: only when user or licence permits storage/processing.
- `index_for_personal_learning`: only with rights/access and explicit user scope.
- `embed_asset`: only when licence/terms allow that display.
- `package_for_offline`: only when local caching/redistribution is allowed and user opts in.

Never infer these from the fact that a file is downloadable.

## Resource metadata contract

Minimum fields:

- `source_id`, `source_name`, `source_type`, `source_url`, `verified_at`, `verification_status`.
- `board_id`, `academic_year`, `grade`, `subject_id`, `medium`, `language_tag` (BCP 47 where practical), `title`, `edition`, chapter metadata.
- `resource_kind` (`textbook`, `syllabus`, `worksheet`, `course`, `image`, `reference_article`, `user_upload`).
- `publisher`, `author`, `source_credit`, `license_name`, `license_url`, `rights_notes`, `rights_reviewed_by`, `rights_reviewed_at`.
- `can_link`, `can_download`, `can_store_original`, `can_process_for_personal_use`, `can_embed`, `can_offline_cache`, `can_redistribute`.
- `external_resource_url`, optional `download_url` only after verification, `checksum` for stored objects, `language_review_status`, `content_quality_status`.

## Catalogue UI rules

Filters: board, academic year, class 6–10, subject, medium/language, resource type, source/publisher and permitted action. Resource cards use honest states: `Official source`, `External link`, `Upload required`, `Open-licensed`, `Permission review needed`, `Unavailable / retry verification`. No fake total counts. If no stable URL exists, open the portal; never fake a download button. Show whether learning content is `Original`, `Reviewed translation`, `AI draft—not reviewed`, or `Not available`.

## Important limitation

This pack lists several source portals across national and state curricula and some individual official pages; it does **not** claim to have downloaded every Class 6–10 book. Broad acquisition requires a resource-by-resource rights audit. Start with a small, verified, permitted seed catalogue and expand systematically.
