# SETU V2 Build Skill

1. Read `00_START_HERE.md`, `01_PROBLEM_STATEMENT_TRACEABILITY.md`, `02_PRODUCT_THESIS_AND_PRINCIPLES.md`, `17_EXECUTION_ROADMAP.md` and `18_MASTER_AGENT_EXECUTION_PROMPT.md`.
2. Verify repository/services before asserting what works.
3. Work vertically: persist data, service, typed API, UI and browser test.
4. Don't hard-code a production subject, language, user or classroom.
5. Keep UI intentional, responsive and accessible; no Tailwind v4/shadcn.
6. Use actual available relevant skills/MCPs and report real names/results.
7. Update `STATUS_REPORT.md` with exact commands/results and blockers.
